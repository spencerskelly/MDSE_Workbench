Phase 0 spike (M0). Not for everyday use.

Install: in a test vault, create `.obsidian/plugins/mdse-workbench/`, put `main.js`, `manifest.json` and `styles.css` from this release in it, then turn on MDSE Workbench under Settings → Community plugins.

`synthetic-vault-60k.zip` is a generated 60,000-note vault with the schema in place, for measuring Workbench in Obsidian before the importer writes a real vault. Unzip it, open the `vault` folder as a vault, install the plugin there, and run **MDSE Workbench: Show diagnostics**.
